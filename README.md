# My IT Portfolio

Personal portfolio website of **Ivan Angelo T. Mortel**, 3rd Year BS Information Technology student.

## Sections
- **About** – name, course, and a short bio
- **Skills** – technical and design skills
- **Projects** – school projects with screenshots and tools used
- **Contact** – email and a simple contact form

## Built with
- HTML, CSS, and vanilla JavaScript
- Google Fonts (Poppins) and Font Awesome icons
- Designed first in Figma (see `design/portfolio-desktop.svg`)

## Folder structure
```
index.html
css/style.css
js/script.js
images/        -> profile photo and project screenshots
design/        -> Figma design export
```

## How to run
Just open `index.html` in a browser, or view the live site on GitHub Pages.
